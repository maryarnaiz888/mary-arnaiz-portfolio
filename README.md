<p class="lead">I focus on quality, evidence and pipeline strength—not simply application volume.</p>
</div>

<div class="card"><div class="number">02</div><h3>Source Proactively</h3><p>Combine inbound applications with targeted searches, social platforms, referrals, communities, job boards and direct outreach.</p></div>
<div class="card"><div class="number">03</div><h3>Assess Evidence</h3><p>Look for relevant work history, portfolios, assessments, examples of output and role-specific evidence—not interview confidence alone.</p></div>
<div class="card"><div class="number">04</div><h3>Present Strong Shortlists</h3><p>Summarize candidate strengths, risks and evidence so hiring managers can make faster, better-informed decisions.</p></div>
<div class="card"><div class="number">05</div><h3>Keep the Pipeline Active</h3><p>Maintain organized candidate stages and build relationships with strong talent before roles become urgent.</p></div>
<div class="card"><div class="number">06</div><h3>Learn From Outcomes</h3><p>Track hiring outcomes and use feedback to improve sourcing, screening and candidate profiles over time.</p></div>
